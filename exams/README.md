# Capelli Sport — CS Certification Exam

Seven parallel exam sets (one per team member), **30 questions each = 210 questions total.** Each set has two sections:
- **Section A — 10 customer-complaint scenarios** (written answers)
- **Section B — 20 multiple-choice questions** (single best answer)

Every set covers the same competencies at the same difficulty, but with **different questions** (different scenarios *and* different MCQs, with correct options spread across A–D), so members can sit the exam side-by-side without sharing answers.

## Folder layout

```
exams/
├── README.md                ← you are here (admin + scoring guide)
├── questions/               ← hand these to the team members (no answers)
│   ├── set-1.md  … set-7.md
└── answer-keys/             ← grader only — keep private
    ├── set-1-key.md  … set-7-key.md
```

## The 10 competency slots (same in every set)

| Q | Competency tested |
|---|---|
| 1 | Shipping & tracking (label-created, delivered-not-received, returned-to-sender, partial/mixed) |
| 2 | Processing time / ETA / **no expedite** |
| 3 | Defective / decoration / wrong item — **evidence photo + same-size replacement** |
| 4 | Returns & exchanges policy — **no exchanges**, 30-day window, personalized rules |
| 5 | Cancellation & refunds — timing gate, refund timing, lost/never-received |
| 6 | Ordering help — individual items, add-to-order, two players, size help, website/phone |
| 7 | Club-controlled — player link / roster / number / **team-store password** |
| 8 | Out of stock — restock, alternative size/color, cancel-or-wait |
| 9 | Escalation & the **leak trap** — complaints, reviews, internal-info handling |
| 10 | Wildcard — multi-issue ticket **or** spot-the-mistake in a drafted reply |

## Scoring (strict)

- **Section A — 10 scenarios × 6 pts = 60.** Grade each against the key's rubric:
  **Route/action (4) · Correct policy stated (3) · Trap avoided (3)** (capped at 6; the spot-the-mistake / multi-issue questions split by items listed in the key).
- **Section B — 20 MCQ × 2 pts = 40.** Correct letter only; the answer table is in each key.
- **Total = 100 per set. Pass = 80 / 100.** Below 80 → retrain on the missed areas and re-sit a different set.
- **Automatic fail on any question** (regardless of the rest) if the answer would:
  leak a club password, RO#, internal team name (ROLO/Dan/BD/Operations), or a
  "do-not-respond" note to the customer; **promise an exchange**; **promise
  expedited shipping**; or **promise a refund/replacement without the required
  check or evidence photo.** These are the non-negotiables.

## How to administer

1. Send each member their `questions/set-N.md` (print or paste — no answer key).
2. Closed-book, 45 minutes, written answers in the customer's-agent voice.
3. Grade with the matching `answer-keys/set-N-key.md`.
4. Record scores; anyone < 80 retrains and re-sits a different set.

> Reference material: the Ticket Coach workflows, the Templates-by-Scenario library,
> the training video, and the real resolved-ticket patterns. Answers should reflect
> **current Capelli policy**, not general customer-service instinct.
